## Overview 

The Single Cell Multiome ATAC + Gene Expression software suite consists of Cell Ranger ARC for the analysis and Loupe Browser for the visualization of chromatin accessibility and 3' gene expression data from the same cell produced by the 10x platform.

To test for differences in mean expression between groups of cells, Cell RangerARC follow the same DE analysis that Cell Ranger, both use the exact negative binomial (NB) test proposed by the authors of the sSeq method (Yu, Huber, & Vitek, 2013). When the counts become large, Cell Ranger switches to the fast asymptotic NB test used in edgeR (Robinson & Smyth, 2007).
Note that Cell Ranger's implementation differs slightly from the sSeq paper, where the size factors are calculated using total UMI count instead of using DESeq's geometric mean-based definition of library size. As with sSeq, normalization is implicit in that the per-cell size factor parameter is incorporated as a factor in the exact and asymptotic probability calculations. More details: https://support.10xgenomics.com/single-cell-multiome-atac-gex/software/pipelines/latest/algorithms/overview#diffexp ; https://www.10xgenomics.com/support/software/cell-ranger/latest/algorithms-overview/cr-gex-algorithm#diffexp 

To swiftly gain an overview of the DE genes within our groups without having to execute the entire Seurat+Signac pipeline, I implemented the following steps:

1. Top 10/20 Differential expression (DE) genes calculated by *cellranger-arc* were extracted directly from `~/outs/analysis/clustering/gex/graphclust/` directory. Within each *cluster*, I organized the *adjusted p-value* column and filtered the data to retain only *p-values<0.05*.

2. Employed a custom list of marker genes (Erik and Top50r/putative Hb) to identify cell types for each cluster and save the results.

3. Utilized **Loupe Browser Navigation for Single Cell** analysis to plot gene distribution. This involved incorporating cluster information generated by *cellrangerARC* from a file named *outs/cloupe.cloupe*, which served as input for generating GEX t-SNE projection for data exploration.


While **Loupe Browser Navigation** serves well for exploratory data analysis (EDA), I've encountered limitations prompting me to explore alternative methods for visualizing gene distributions derived from cell ranger-arc outputs. This effort is currently ongoing, and I am actively seeking a more effective solution.

### Top DGE genes

<br>

We evaluated two criteria:

1) The first top 10 DGE genes by cluster.

2) The first top 20 DGE genes by cluster.

<br>

DGE genes were organized by *adjusted p-value* and posterior *values<0.05* were kept. A subset of the top 10 or top 20 genes were then used to search for markers. Below is provided an example:
